\caption{%
\textbf{Pairwise $\hat{R}$ values induce a graph-based diagnostic for MCMC
convergence and multimodality.}
(a)~Six MCMC chains after warm-up, plotted against sample iteration $t$;
chains~1 and~2 explore one posterior mode, whereas chains~3--6 explore
another.
(b)~Pairwise statistics $\hat{R}_{ij}$ for $i<j$.
Shaded cells indicate $\hat{R}_{ij}<\rho$, where $\rho>1$ is the convergence
threshold.
(c)~The MCMC convergence graph $G_{\rho}$ takes the chains as nodes and adds
an edge $\{i,j\}$ whenever $\hat{R}_{ij}<\rho$.
Its connected components correspond to the explored posterior modes.
}
